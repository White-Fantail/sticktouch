## 공통 연동

- `src/games/creative-arcade/game.ts`: 순수 게임 상태·판정 및 `GameEvent` 발행.
- `src/games/creative-arcade/scene.ts`: 게임별 Canvas 시각 효과, 음악 패드·음계·실제 손선·극장 커튼·실루엣.
- `catalog.ts` + `registry.ts`: `creative` 카테고리, 7개 개별 URL, 60초 권장 및 30/45/60초 선택.
- `runtime.ts`: 카메라 신뢰도에 따른 라운드 진행 차단, 동일 좌표 매핑·미러링 공유.
- `audio.ts`: 게임 이벤트의 `pitch`·`instrument` 메타데이터로 드럼/건반/현악/관악/드로잉 소리를 Web Audio에서 **SFX 채널**로 재생. 끔/볼륨 0/일시정지면 재생하지 않음.
- 기존 `GameStage`의 음악, 15초 페버, 콤보, 점수, 일시정지, 설정 및 공유 동작을 유지함. 이미지·음성·마이크 데이터 저장 또는 전송은 하지 않음.

## 기본 품질과 불가피한 제약

- 가만히 겹친 부위는 터치로 인정하지 않음. 손 이동은 노이즈 제거를 위해 최소 이동량을 요구.
- 포즈 게임은 시작부터 목표 자세가 같아도 인정하지 않으며, **먼저 자세를 풀고 다시 구성**해야 함.
- 손·발·관절의 신뢰도가 부족할 때는 타이머와 점수를 정지하고 입력 상태를 재설정함. 추적 손실 자체에 대한 오답/벌점 없음.
- 그림은 메모리 내부 최근 선분 320개만 유지하며 기기 밖으로 전송하지 않음. 라운드 종료 후 기본적으로 영구 저장하지 않음.
- 카메라는 단안 2D Pose 추정이므로 실제 3D 공중 위치/몸 뒤쪽 동작을 정확하게 재구성할 수 없음. '그림자'는 포즈 랜드마크 관절 연결을 시각화한 실시간 연출이지 배경 제거/실제 광학 실루엣 합성이 아님.
- 에어 드러머는 4패드 리듬 게임, 뮤직 메이커는 6음계 연주 게임; 전문가용 MIDI 작곡/녹음·정밀 악기 연주는 범위 밖.

## 검증

CI: `npm run test && npm run check && npm run build`, `tests/creative-arcade.test.ts` 내 드럼 재진입·잘못된 부위·정지·손 스와이프·그림 선분·포즈 재구성·실루엣 좌표·시간/일시정지 회귀.

별도의 **실기기 확인 필요**:
1. 모바일 Safari와 Chrome에서 손바닥 미러링 및 중심 현 횡단이 제대로 동작하는지 확인.
2. 온몸(발 포함)을 카메라에 넣었을 때 드럼 아래 두 패드 타격이 가능한지 확인.
3. 카메라 모델 지연, 15초 가속, 배경 전환/권한 거부/일시정지 후 귀환을 확인.
4. 음색·음량·각 악기 울림이 iPhone/Android/PC 기기의 오디오 출력마다 구별되는지 확인.
5. 손 그리기와 관절 무대 실루엣이 저성능 기기에서도 끊김 없이 렌더링되는지 확인.
