# 2인용 모션 게임: 무궁화 꽃 / 줄넘기 대결

## 무궁화 꽃이 피었습니다
- ID: \`red-light-green-light\` (2인 대결, 권장 60초).
- 컴퓨터 술래의 초록/빨강 신호에 따라 움직임·정지를 판정한다. 초록일 때 몸통 위치와 손·발의 상대 이동량을 가상 트랙 진행률로 환산하여 P1/P2 캐릭터를 화면 위쪽에서 이동시킨다.
- 빨강 신호에는 0.42초 유예 후 정지 자세에서 상당한 움직임이 0.16초 이상 이어질 때만 해당 플레이어를 출발점으로 돌린다. 다른 플레이어는 유지된다. 먼저 술래에게 도착(100%)하면 즉시 승리.
- 고정 웹캠에서 실제 앞뒤 거리를 직접 측정할 수 없으므로 이동량을 **가상 전진**으로 표현한다. 제자리 걸음으로도 진행 가능.

## 줄넘기 대결
- ID: \`jump-rope-duel\` (2인 대결, 권장 60초).
- 어깨 아래/허리 주변 손의 반복 위·아래 움직임을 **몸통 상대 좌표**로 확인하고, 두 손의 회전 동작과 몸통 상승·착지가 함께 확인될 때 1회 기록한다.
- 손만 흔들기 또는 점프만 하기에는 점수가 주어지지 않는다. 줄 걸림 페널티·감점이 없으며 제한 시간 종료 시 더 많은 횟수의 플레이어가 승리한다.
- 가상의 줄은 각 플레이어의 추적 손목에서 출발해 휘어지는 곡선으로 렌더링한다. 2D 영상으로 실제 줄의 깊이 방향 회전은 완전히 측정할 수 없으므로 손 회전 동작을 근사한다.

## 공통 및 검증
- 기존 DuoGameStage의 2인 인식, 일시정지/간편 설정, 30/45/60초, 소리 및 효과를 재사용한다. 한 명이라도 사라지거나 카메라가 멈추면 판정과 타이머가 멈추고 추적 재개 시 움직임 기준점을 초기화한다.
- 단일 플레이어 게임 로직·기록에는 영향을 주지 않는다.
- \`npm test\`, \`npm run check\`, \`npm run build\` 및 실제 웹캠·모바일 테스트로 다양한 키·거리·조명에 대한 임계값을 점검한다. 뛰기 전에 충분한 공간을 확보하고 두 플레이어는 서로 떨어져 선다.
